### 第六阶段：app.py 系统级重构（4 文件新建 + 1 文件重写）

**目标：** 拆分 2770 行巨石 `App` 类为骨架 + 侧边栏 + 主内容区。

**重构成果：**

| 文件 | 行数 | 角色 |
|---|---|---|
| `ui/app.py` | 2770 → **1552**（-44%） | 骨架：窗口生命周期、菜单、快捷键、生成编排、面板协调 |
| `ui/sidebar.py` | **767**（新建） | HistorySidebar：历史列表、搜索、标签筛选项、卡片渲染、缩略图加载、_Tooltip |
| `ui/main_content.py` | **608**（新建） | MainContent：输入区、Notebook 标签页、预览/对比渲染、生成控件、状态栏 |
| `ui/app_protocol.py` | **36**（新建） | AppProtocol 接口：12 个属性/方法契约 |

**架构对比：**

```
之前: App 类 (2770 行) — 布局 + 历史 + 生成 + 预览 + 导出 + 设置全部耦合

之后: App (1552 行) — 编排器
      ├── HistorySidebar (767 行) — 通过 self.app 访问 AppProtocol
      │   ├── _Tooltip
      │   ├── 历史卡片 + 缩略图
      │   ├── 搜索 + 防抖
      │   └── 标签筛选项
      ├── MainContent (608 行) — 通过 self.app 访问 AppProtocol
      │   ├── Notebook（预览/变体/队列/日志）
      │   ├── 生成控件
      │   └── 状态栏 + 统计
      └── AppProtocol — 面板的接口契约
```

**关键架构决策：**
- 面板（BatchPanel、QueuePanel）现在接收 `self.app`（即 App 实例）而非 `self`（旧 App 引用）
- 转发属性（`pt`、`pv`、`_nb` 等）保持向后兼容性
- `_gen()` 通过 `self.content.pt`、`self.content.pv` 访问控件
- `_refresh_hist()` 委托给 `self.sidebar.refresh()`
- 零残留引用验证通过

## 五、已知局限与后续建议

1. **运行时主题切换：** 当前 `apply_theme()` 只修改 `C` 字典，现有 Widget 不会自动更新颜色。需实现递归 Widget 遍历器或要求重启生效。
2. **i18n 覆盖不完整：** 部分动态字符串（日志消息、Provider 名称、外部链接文本）尚未纳入 i18n 注册表。
3. **单元测试：** 项目仍然零测试。建议至少为 `data/repository.py` 和 Provider 函数添加 pytest。
4. **`app.py` 仍有 1552 行：** `_show_stats()`、`_open_app_settings()` 等方法仍内联在 App 中，可进一步提取。
5. **Type hints：** AppProtocol 使用了 `Protocol`，但实际类未标记为遵循该协议。建议在 Python 3.12+ 中使用 `class App(AppProtocol):` 显式声明。
