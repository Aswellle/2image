# 2image v2.11.0

本次更新的主线是**提示词资产管理与统计洞察的能力补齐，以及三家图像接口的模型换代**：词库从单一浏览列表升级为可分类、可模板化、可导入导出并带使用概况的提示词资产管理器；统计看板新增收藏率、近 7 天趋势、成本估算与 CSV / 分享图导出；提示词助手支持一次生成 3 个候选、跨会话历史与完整键盘操作。同期完成火山引擎 Seedream 5.5、通义万相 2.6 同步协议与 MiniMax H3 目录更新，存量模型 ID 自动归一化。配置、历史数据库、标签、图片与自定义词库完全兼容，升级后无需手动迁移。

## 主要更新

### 词库（提示词片段库）

- **自定义分类**：支持新建任意分类，长分类名自动换行，分类栏宽度随窗口缩放与英文界面适配。
- **模板变量填充**：词条中的 `{{变量}}` 在追加时弹窗逐项填写，支持中文变量名；留空时给出明确提示并保留对话框。
- **词条说明可编辑**：自定义词条可编写说明，随悬浮提示展示，并随导出文件一起迁移；说明查表键统一去除首尾空白。
- **导入 / 导出**：自定义词库可导出为 JSON（v2 格式，含说明）并在另一台机器合并导入；写入采用临时文件原子替换，中断不会留下半截文件；导出失败会给出错误回执。
- **搜索增强**：搜索覆盖词条的中英双语说明；结果标注归属分类、显示命中数量，并在跨分类搜索时禁用“新建词条”；输入改为防抖过滤，词库较大时不再逐字符卡顿。
- **使用频次与上下文**：词条按使用次数置顶；悬浮说明展示该词条在历史生成记录中的使用概况；新增、删除或导入后停留在当前分类，新词条不会“消失”。
- **一键沉淀**：历史卡片可一键把提示词保存到「⭐ 我的词条」；重复词条会明确提示且不会重复写入。

### 统计看板

- **新增指标**：收藏率卡片、近 7 天趋势柱状图、连续生成天数，以及成本估算分区（历史估算 + 今日台账 + 日预算进度）。
- **新增导出**：一键导出多分区 CSV（Excel 直接打开）与 1280×900 分享图；CSV 已防止表格公式注入，分享图标签按可用宽度收纳，超长标签不再溢出画布。
- **分布与热度**：接口使用分布、标签热度 Top-10，明确标注全时段口径与百分比语义。
- **交互完善**：刷新改为就地重绘（保留滚动位置与年份选择）、年份切换、滚轮仅作用于看板、Escape 关闭、空库给出引导说明。
- **显示修复**：热力图空数据格子不再出现装饰性描边；宽面板内水平居中；悬浮提示钳制在屏幕内；“近 7 天”计数与趋势图口径一致。

### 提示词助手

- **多候选生成**：一次生成 3 个候选，通过 ‹ / › 或左右方向键切换；切换条随模板结果正确清理，失败候选不会中断其余候选。
- **键盘可用性**：模板卡片支持 Tab 聚焦、Enter / Space 选中、方向键在卡片间移动；参数页空态提供模板直达入口。
- **跨会话历史**：生成历史持久化保存并保留最近 8 条，打开助手即可从下拉框调用。
- **生成保护**：一键重试沿用上次参数；重新生成前保护手动编辑过的内容；生成中关窗需确认，Escape 同样受保护。
- **布局修复**：状态文字独立成行、错误详情自适应换行、结果区改网格布局，底部不再被裁切；窗口几何按屏幕工作区钳制。

### 模型时效性与网络

- **火山引擎 Seedream 5.5**：默认切换为 Seedream 5.5，保留 5.0 Pro / 5.0 Flash 可选；4.x 与 SeedEdit 旧通道退役，存量配置中的旧模型 ID 会自动归一化到新默认。
- **通义万相 2.6**：新增 `wan2.6-t2i` 同步协议支持，`wan2.5-t2i` 继续可用；生成结果标注实际模型名，畸形同步响应按“无效响应”归类并触发回退。
- **MiniMax H3**：目录换代到 MiniMax-H3-Image / Highspeed（文生图，最高 20MP）。新编辑端点适配中，**本版 MiniMax 图生图暂不可用**，请暂时改用其他支持参考图的接口。
- **计价校准**：付费接口估算单价对齐 FLUX.2 等现役模型。
- **错误可读性**：非 JSON 错误响应保留供应商给出的具体原因，限流与失败日志不再只剩状态码。

### 界面、交互与可访问性

- **二次确认**：侧栏“重置”和“清空历史”新增确认框，并分别说明会影响与不会影响的内容；不可逆操作默认按钮改为“取消”，避免回车误确认。
- **模态一致性**：确认、编辑与配置对话框统一归属主窗，点击对话框以外不会关闭或把窗口推到主窗后面；配置向导关闭确认补齐警告图标。
- **可访问性**：强度滑杆支持 Tab 聚焦与 ← / → / Home / End；图标按钮补充悬浮说明，键盘聚焦同样可见；说明气泡自动避开屏幕边缘。
- **视觉统一**：下拉框字段、箭头与弹出列表统一为令牌派生风格；供应商信息卡空白占位不再露出白色竖条；About 更新进度条样式跟随当前主题。
- **小屏与高 DPI**：设置与快捷键窗口缩小时优先保证底部操作按钮可见；统计分区与弹窗继续按系统缩放系数适配。

### 稳定性与测试

- **端到端测试套件**：新增 81 项真实界面旅程测试，覆盖启动、生成、历史、词库、统计、助手、设置与对话框的交互联动。
- **回调异常守卫**：测试期捕获 Tk 回调异常并判定失败，修复了多候选进度、内联重命名、词库校验等一批“界面静默失效”问题。
- **失败回执**：词库导出、统计刷新、提示词历史落盘失败均给出可见提示，不再静默无反应。
- **CI**：质量门禁 + Windows 测试（Python 3.11 / 3.12 双矩阵）全部通过，作业超时保护已启用。

## 下载与安装

- **安装包**：下载 `2image-setup-v2.11.0.exe`，运行后按向导安装。
- **便携版**：下载 `2image-portable-v2.11.0.exe`，无需安装即可直接运行。
- 配置、历史数据库、标签、图片与自定义词库完全兼容，升级后无需任何手动操作；已内置应用内更新的用户可直接在关于窗口完成升级。
- 若此前依赖 MiniMax 图生图，请暂时改用其他支持参考图的接口（新编辑端点适配完成后恢复）。
