# 2image v2.11.0

本次更新把「词库」和「统计看板」从辅助功能升级为完整工作流，提示词助手补齐多候选与键盘操作；同时完成三家供应商的模型换代，并系统性修复对话框、导出与高 DPI 交互细节。

## 主要更新

### 词库（提示词片段库）

- **自定义分类**：支持新建任意分类，长分类名自动换行，分类宽度随窗口缩放。
- **模板变量填充**：词条中的 `{{变量}}` 在追加时弹窗逐项填写，支持中文变量名；留空会明确提示。
- **词条说明可编辑**：自定义词条可编写说明，随悬浮提示展示，并随导出文件一起迁移。
- **导入 / 导出**：自定义词库可导出为 JSON（v2 格式，含说明）并在另一台机器合并导入；写入采用临时文件原子替换，中断不会留下半截文件。
- **搜索增强**：搜索覆盖词条的中英双语说明；结果标注归属分类、显示命中数量，并禁用“新建词条”避免写错分类；输入改为防抖过滤，词库较大时不再逐字符卡顿。
- **使用频次与上下文**：词条按使用次数置顶；悬浮说明展示该词条在历史生成记录中的使用概况；新增/删除/导入后停留在当前分类。
- **一键沉淀**：历史卡片可一键把提示词保存到「⭐ 我的词条」；重复词条会明确提示且不会重复写入。

### 统计看板

- **新增指标**：收藏率卡片、近 7 天趋势柱状图、连续生成天数、成本估算（历史估算 + 今日台账 + 日预算进度）。
- **新增导出**：一键导出多分区 CSV（Excel 直接打开）与 1280×900 分享图；CSV 已防止表格公式注入，分享图标签按可用宽度收纳。
- **分布与热度**：接口使用分布、标签热度 Top-10，明确标注全时段口径与百分比语义。
- **交互完善**：刷新改为就地重绘（保留滚动位置与年份选择）、年份切换、滚轮仅作用于看板、Escape 关闭、空库给出引导说明。
- **显示修复**：热力图空数据格子不再出现装饰描边；宽面板内水平居中；悬浮提示钳制在屏幕内；“近 7 天”计数与趋势图口径一致。

### 提示词助手

- **多候选生成**：一次生成 3 个候选，通过 ‹ / › 或左右方向键切换；切换条随模板结果正确清理。
- **键盘可用性**：模板卡片支持 Tab 聚焦、Enter/Space 选中、方向键切换；参数页空态提供模板直达入口。
- **跨会话历史**：生成历史持久化保存并限制最近 8 条，打开助手即可从下拉框调用。
- **生成保护**：一键重试沿用上次参数；重新生成前保护手动编辑过的内容；生成中关窗需确认，Escape 同样受保护。
- **布局修复**：状态文字独立成行、错误详情自适应换行、结果区改网格布局，底部不再被裁切；窗口几何按屏幕工作区钳制。

### 模型与网络

- **豆包 Seedream 5.5**：默认切换为 Seedream 5.5，保留 5.0 Pro / 5.0 Flash；4.x 与 SeedEdit 旧通道退役，存量配置中的旧模型 ID 会自动归一化到新默认。
- **通义万相 2.6**：新增 wan2.6-t2i 同步协议支持，wan2.5 继续可用；返回结果标注实际模型名。
- **MiniMax H3**：换代到 MiniMax-H3-Image 系列（文生图）。新编辑端点适配中，**本版 MiniMax 图生图暂不可用**。
- **计价校准**：付费接口估算单价对齐 FLUX.2 等现役模型。
- **错误可读性**：非 JSON 错误响应保留供应商给出的具体原因；畸形同步响应按“无效响应”归类并触发回退，而不是把内部异常抛给界面。

### 界面与交互

- **二次确认**：侧栏“重置”和“清空历史”新增确认框并给出对应后果说明；不可逆操作默认按钮改为“取消”，避免回车误确认。
- **模态一致性**：全部确认/编辑/配置对话框归属主窗，点击对话框以外不会关闭或把窗口推到主窗后面；配置向导关闭确认补齐提示图标。
- **可访问性**：强度滑杆支持 Tab 聚焦与 ←/→/Home/End；图标按钮补充悬浮说明，键盘聚焦同样可见。
- **视觉统一**：下拉框字段、箭头与弹出列表统一为令牌派生风格；供应商信息卡空白占位不再露出白色竖条；About 更新进度条样式跟随当前主题。
- **小屏与高 DPI**：设置/快捷键窗口缩小时优先保证底部操作按钮可见；测试面板与统计分区按缩放系数适配。

### 稳定性与测试

- **端到端测试套件**：新增 81 项真实界面旅程测试（启动、生成、历史、词库、统计、助手、设置、对话框），覆盖全功能交互联动。
- **回调异常守卫**：测试期捕获 Tk 回调异常并判失败，修复了多候选进度、内联重命名、词库校验等一批“静默失效”问题。
- **失败回执**：词库导出、统计刷新、提示词历史落盘失败均给出可见提示，不再静默无反应。
- **CI**：quality / test（3.11、3.12）双矩阵全部通过，作业超时保护已启用。

## 下载与安装

- **安装包**：下载 `2image-setup-v2.11.0.exe`，运行后按向导安装。
- **便携版**：下载 `2image-portable-v2.11.0.exe`，无需安装即可直接运行。
- **兼容性**：配置、历史数据库与自定义词库向后兼容，无需手动迁移；旧版模型 ID 会自动归一化。若此前依赖 MiniMax 图生图，请暂时改用其他支持参考图的接口。
