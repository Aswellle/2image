# 2image v2.6.0

本次更新以**安全与正确性**为核心：修复了火山引擎图片下载的安全防护绕过、旧版 JSON 历史迁移可能静默丢数据的问题；生成主流程三处断链全部修复——生成成功后界面卡住、新配置的 API Key 需重启才生效、付费接口配置重启丢失；付费日预算防线完整恢复生效。生成可控性升级：**模型队列类接口的轮询任务现在可随时取消，立即中断而非空转到超时**。界面语言精简为**简体中文与 English** 双语，繁体旧配置自动回落，无需手动操作。

## 主要更新

### 安全与数据保护

- **火山引擎图片下载接入安全通道**：豆包返回的图片 URL 此前未经校验直接下载，已接入与全部其他接口一致的 SSRF 防护下载通道（内网地址拦截、重定向逐跳校验、25MB 上限、Content-Type 白名单）。
- **旧版 JSON 历史迁移不再丢数据**：迁移改为逐条校验写入，主键冲突的记录会计入失败并保留原始文件，不再出现"报告全部成功、实际部分丢失"后把源文件归档的情况。
- **图片下载统一限长**：直接返回图片二进制的五个接口（Stability/Cloudflare/HuggingFace/Segmind/Pollinations）全部接入 25MB 上限，异常响应不再可能耗尽内存；Pollinations 重定向后的最终地址同样过安全校验。

### 生成流程正确性

- **生成成功后界面不再卡住**：恢复被重构误删的成功回调，单图生成完成后按钮/进度条/预览/历史列表正常联动；协议合规护栏同步扩扫应用控制器目录，杜绝同类回归漏网。
- **新配置的 Key 即时生效**：生成控制器不再缓存旧配置引用，向导保存后无需重启即可使用新填写的接口。
- **付费接口配置落盘**：付费配置向导与免费向导语义对齐，OpenAI/Stability/Replicate/豆包/BFL 的 Key 与模型选择保存后重启不再丢失。
- **付费日预算防线恢复生效**：修复供应商身份记录错位导致付费消耗从未计入台账的问题；批量变体路径补齐 Key 与预算预检，自动回退链不再包含未配 Key 或未授权的付费接口——三条付费消费入口全部收口。
- **翻译等待纳入取消保护**：中文提示词翻译的限流等待期间点击停止可立即中断。

### 生成可控性

- **轮询任务可随时取消**：Replicate、通义万相、BFL、fal.ai、StableHorde、ModelsLab 等"提交后排队"型接口的任务轮询接入取消通道，点击停止后在下一秒内中断，不再空转最长 6 分钟。

### 供应商稳定性

- **批量并发不再互相阻塞**：七个供应商的重试与限流等待移出串行锁（统一为时间槽预占模式），此前 429 退避与 HTTP 超时全程持锁，六格变体并发时其余线程最长被阻塞约 5 分钟。
- **GPT-Image 错误解析加固**：网关返回非 JSON 错误体时不再丢失真实 400 详情，响应缺字段不再崩溃。
- **熔断器半开状态落实单探针**：熔断恢复期只放行一个探测请求，探测失败立即重回熔断并重置冷却。
- 错误日志统一脱敏，429 类错误被正确分类后按退避策略重试。

### 界面与体验

- 错误提示不再以成功配色显示；统计看板防重复堆叠；对比选图弹窗缩略图改有界线程池（此前一次弹窗最多创建 200 个线程）；查看器大图极限放大增加像素内存预算，不再冻结。
- 词库搜索结果中删除词条按真实归属分类执行（此前跨分类搜索时会删错）；Toast 通知渲染异常不再卡死后续通知；批量变体飞行中启动单图生成不再污染变体的提示词。
- 生成、队列、预算、Key 引导、导出、收藏、重命名等十余处弹窗文案接入多语言，英文界面完整可读。

### 配置与基础设施

- 清理配置文件中六个重复定义的键，补齐 MiniMax/通义万相/Bria/BFL 四个接口缺失的配置键（此前只能手改配置文件）；环境变量覆盖按类型显式转换，`0`/`false` 不再被误判为开启。
- 日志冲刷不再永久死锁并支持超时；自定义短语词库改原子写入，文件损坏时保留备份不再被空数据覆盖；场景路由关键词按词边界匹配（"UI" 不再误命中 "fruit"）；字体下载改流式限长；翻译请求不再阻塞后续翻译；打包版迁移提示改写入日志文件（原控制台输出在安装版中不可见）。

### 界面语言

- **精简为简体中文与 English 双语**：移除繁体语言包与切换项；原使用繁体的用户升级后自动回落为简体中文，无需任何手动操作。

### 开发者可见

- **测试套件扩至 524 项**：新增注册表一致性护栏（7 项，锁定 provider 元数据单一真相）、协议合规 AST 扫描扩展至应用控制器；测试磁盘写入隔离扩展至数据库/日志/图片/词库/台账六处路径绑定，任何用例都无法触碰真实用户数据；治理三处重名测试定义。
- 供应商元数据漂移治理：manifest 与模块注册表对齐，Cloudflare 双凭证贯通路由/控制器/顶栏可用性判断；供应商速查表补全至 23 项。
- 构建脚本默认图标改为仓库相对路径，换机构建不再失败；AGENTS.md 与项目现状全面同步。

## 下载与安装

- **安装包**：下载 `text2image_pro_v2.6.0.exe`，运行后按向导安装。
- **便携版**：下载 `text2image_pro.exe`，无需安装即可直接运行。
- 配置与历史记录完全兼容，升级后无需任何手动操作。繁体用户将自动切换为简体界面；付费消耗台账自本版起正确累计，此前的日预算防线在 v2.5.0 及更早版本中实际未生效，升级后当日消耗从零起算。
