# 2image v2.12.0

本次更新的主线是**商业接口全面接入与智能路由补全**：Ideogram、fal.ai、Recraft、MiniMax 与豆包 Seedream 现与免费 / 付费接口同级出现在主界面下拉框，全部 23 个接口（12 免费 + 6 付费 + 5 商业）都可以在配置向导中完成 Key 与模型设置；MiniMax H3 新增参考图编辑，图生图接口增至 8 个。同期补齐了智能路由此前未接通的链路——单图、批量变体与顺序队列共用场景路由，提示词模板优先真正生效，Pollinations 开关、Cloudflare 双凭证与图生图能力过滤均按预期工作。配置、历史数据库、标签、图片与自定义词库完全兼容，升级无需手动迁移。

## 主要更新

### 商业接口全面接入

- **主界面下拉框**：新增「商业接口」分组，Ideogram v4、fal.ai FLUX.2 Pro、Recraft V4.1、MiniMax H3 与豆包 Seedream 与免费 / 付费接口同级可选；顶栏新增商业接口可用数徽标。
- **配置向导**：付费向导补齐 xAI、Ideogram、fal.ai、Recraft（模型 + 风格）、MiniMax（模型）卡片；免费向导补充 OpenRouter 卡片。全部接口都有前端配置入口，不再需要手改 `config.json`。
- **图生图入口**：fal.ai 与 MiniMax H3 进入图生图下拉框，可选接口由 6 个增至 8 个。

### MiniMax H3 图生图

- **参考图编辑**：接入官方 `/v1/images/edits`，参考图以 data URI 提交（PNG / JPEG / WebP 直传，其余可解码格式自动转码），使用 `size=auto` 搭配宽高比与面积档，最高 20MP。
- **计费安全**：编辑端点非幂等，超时、5xx、图片下载失败与响应解析异常均不自动重试，避免重复扣费；同步请求最长等待约 10 分钟，日志与向导会给出明确提示。
- **模型选择**：MiniMax-H3-Image 默认，H3-Image-Highspeed 可选。

### 智能路由补全

- **队列与模板**：顺序队列的「自动」模式在任务执行时按提示词路由，与单图 / 批量行为一致；提示词助手应用模板后，模板场景优先会随单图、批量与队列任务传递，提示词被改写后自动失效。
- **兜底链路**：修复最终兜底从未执行的问题；显式选择接口失败后会按可用性继续尝试其他接口，图生图兜底严格限制在支持参考图的接口内，不会静默忽略参考图。
- **可用性**：关闭 Pollinations 后路由、兜底与接口调用都不再触发；Cloudflare 必须 Account ID 与 API Token 同时就绪；付费 / 商业接口默认仍不参与自动模式，开启 opt-in 后受日预算约束。
- **场景覆盖**：BFL、Replicate、xAI 与 Nano Banana Pro 加入产品图 / 电商 / 品牌 / 插画 / 社媒等场景；新增小红书、公众号、社媒、封面等关键词，社媒场景无需模板也可命中。
- **可核对**：自动路由会在日志中输出识别到的场景与前几位接口；兜底顺序与免费接口注册表保持一致。

### 配置与稳定性

- **付费预算校验**：拒绝 nan、inf 与负数，配置异常不再导致付费向导打开失败。
- **自定义模型**：xAI 与 Recraft 手填的目录外模型 ID 在向导保存后原样保留，不再被静默改回默认。
- **界面稳定性**：修复强度滑杆数值回调在窗口销毁后触发 TclError 的问题。

## 下载与安装

- **安装包**：下载 `2image-setup-v2.12.0.exe`，运行后按向导安装。
- **便携版**：下载 `2image-portable-v2.12.0.exe`，无需安装即可直接运行。
- 配置、历史数据库、标签、图片与自定义词库完全兼容，升级后无需任何手动操作；已内置应用内更新的用户可直接在关于窗口完成升级。
- **行为说明**：队列的「自动」模式现在与单图共用路由，开启付费自动路由后会按场景尝试付费接口；显式选择接口失败时也会继续按可用性兜底。MiniMax 图生图为同步请求，取消需等待当前请求返回后生效。
