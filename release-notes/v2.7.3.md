# 2image v2.7.3

本次更新集中修复界面上「看起来能用、实际没有生效」的一批问题：菜单与按钮上标注的快捷键此前从未绑定，供应商下拉框显示的是内部标识而非接口名称，四个已经实现参考图的接口在图生图模式下选不到；同时修复窄窗口下「生成」按钮被裁出可视区、按钮按下瞬间闪白、深色图与画布边界消失等观感缺陷。

## 主要更新

### 图生图接口恢复

- **四个接口重新出现在图生图下拉框**：Gemini Nano Banana、OpenAI GPT-Image、MiniMax Image、豆包 Seedream 均已实现参考图逻辑，但注册表未声明图生图能力，导致配好 Key 也选不到。现已补全声明，图生图可用接口从 4 个增加到 8 个。
- **下拉框按「是否配好 Key」筛选，而非按接口分类**：此前用免费/付费分类判断接口能否使用，与向导里实际有没有配置卡片不是一回事——豆包属于商用分类但付费向导已有完整配置卡片，却被排除在图生图下拉框外。现改为以实际配置能力为准，并新增测试从两个向导源码中提取真实写入的配置键做比对，避免这张表再次漂移。
- **下拉框显示接口名称而非内部标识**：此前直接渲染注册表 key，用户看到的是 `bria_ai`、`gemini_nano_banana_pro` 这类内部标识。现显示人类可读名称，生成、变体、队列、侧栏四条派发路径在边界处统一转回稳定 ID。

### 快捷键与输入

- **补齐五个从未绑定的快捷键**：界面多处标注 Ctrl+B / Q / L / P / 2 可用，但代码里从未绑定，按下毫无反应。现已全部绑定；其中 Ctrl+B、Ctrl+L 在文本控件内原本是编辑键（光标后退、清行），走了输入焦点守卫，打字时不会被弹窗打断。
- **菜单快捷键改用系统绘制**：快捷键从拼进菜单文字改为原生 accelerator 显示，由 Tk 右对齐绘制、使用系统字体，切换语言后不会错位。
- **快捷键说明收敛为一处**：主界面原先在四处重复罗列快捷键，现只保留 Ctrl+Enter（在输入框内触发、没有对应菜单项），其余由菜单栏承载；状态栏回归纯状态显示。

### 布局与窄窗口

- **窄窗口不再裁掉生成按钮**：侧栏宽度上限原是固定 600px，与窗口宽度无关。窗口缩到最小（1000px）时若侧栏拖到上限，右侧工作区只剩 366px，「🎨 生成」按钮被整个裁出可视区。现侧栏上限随窗口宽度动态收缩，保证工作区至少保留 760px。
- **次要提示自适应让位**：工具行的 Ctrl+Enter 说明与预览工具栏的双击提示在窄窗口下会把自己压成几像素残片并挤掉按钮。现按可用宽度决定显示与否——提示是补充信息，按钮是操作入口。
- **下拉框不再截断长接口名**：ttk 弹出列表的宽度此前无论如何设置都固定为 20 列。现直接配置弹出列表的列宽，并按中文与 emoji 占 2 列计算所需宽度，控件本身同步加宽，最长的接口名也能完整显示。

### 视觉与可读性

- **按钮按压与禁用态改用自绘配色**：按钮的按压底色、按压文字色、禁用文字色此前全部回落到 Windows 系统色——深色界面里每次点击都闪一块白，禁用态的系统灰落在饱和底色上只有 1.35:1。现按压底色由常态底色派生，禁用态底色压暗、文字按对比度重新取色，图标按钮按图形对象的 3:1 判定。运行时创建的对话框、向导、面板按钮同样覆盖。
- **七组低对比度文字修复**：收藏按钮的两种状态、队列空状态提示、搜索框占位符、图生图提示条与四处破坏性操作均低于 4.5:1 阈值，其中最低仅 1.35:1。全部改用既有主题令牌，未新增颜色值。
- **空状态提示可读了**：对比画布、批量格、参考图预览、历史与队列缩略图的空态提示原本只有 1.5–2.2:1，首次打开时几乎看不到「这里能做什么」。统一提升至 6.2–6.8:1。
- **图片加 1px 描边**：深色图落在深色画布上时边界几乎消失（1.21:1），只能靠四周留白判断范围。预览、对比、批量缩略图与查看器四个图像面统一加一圈低透明度描边，查看器的描边跟随拖拽与每一帧缩放。
- **主界面标题改用产品名**：窗口标题栏与顶部栏原显示「✨ 文字生图工具 v10」，既不是产品名，版本号也与实际版本对不上。现统一为 `2image`。
- **两套悬浮提示统一节奏**：侧栏气泡提示与词条库说明卡的延迟相差 1.5 倍、淡入时长相差 2.2 倍，看起来像其中一个坏了。现共用一套参数（400ms 延迟、约 150ms 缓出淡入）。

### 数据安全

- **丢弃变体改走安全删除通道**：批量面板丢弃变体时原先在后台线程直接调用 `os.remove`，绕过了 `data/file_ownership` 的路径校验，路径穿越与符号链接防护对该入口完全失效。现改为经 `safe_delete_file()` 删除，越界路径与已删除文件静默忽略。

## 下载与安装

- **安装包**：下载 `2image-setup-v2.7.3.exe`，运行后按向导安装。
- **便携版**：下载 `2image-portable-v2.7.3.exe`，无需安装即可直接运行。
- 配置、历史数据库、标签、图片与词库完全兼容，升级后无需任何手动操作；已内置应用内更新的用户可直接在关于窗口完成升级。
