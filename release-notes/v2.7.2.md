# 2image v2.7.2

本次更新修复应用内更新安装流程的关键缺陷，并优化关于窗口与启动向导的用户体验。

## 主要更新

### 应用内更新修复

- **独立更新器参数传递修复**：`2image_updater.exe` 复制自身到运行时目录后重新执行时，未能继承原始命令行参数（`--installer`、`--expected-sha256` 等），导致安装流程静默失败。现修复为完整传递 `sys.argv[1:] + --runtime`，更新安装恢复预期行为。

### 用户体验修复

- **启动向导不再重复弹出**：用户关闭或跳过免费接口配置向导后，`show_wizard_on_start` 偏好已正确持久化，下次启动不再自动弹出。
- **关于窗口优化**：窗口尺寸从 560×560 增大至 640×680，完整显示版本信息、更新状态与操作按钮；进度条采用自定义样式（trough 深色背景 + 亮色填充），下载进度更易辨识。
- **GitHub 仓库直达**：关于窗口新增 🐙 GitHub 按钮，点击直接跳转开源项目页面。

## 下载与安装

- **安装包**：下载 `2image-setup-v2.7.2.exe`，运行后按向导安装。
- **便携版**：下载 `2image-portable-v2.7.2.exe`，无需安装即可直接运行。
- 配置、历史数据库、标签、图片与词库完全兼容，升级后无需任何手动操作。

- 完整测试套件：618 项通过，0 失败。
