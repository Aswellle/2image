# 2image v2.3.1

本次更新扩展了模型目录并新增一个付费供应商：OpenAI GPT-Image 家族新增 **2.5-flare**（快速高质量）与 **2.5-sunburst**（最强画质）两个型号，默认模型从 gpt-image-1 升级至 **gpt-image-2**；Google Gemini Nano Banana 家族新增 **v2 Lite** 与 **Pro** 版本，默认从即将下线的 v1 切换至 **Nano Banana 2**；新增付费供应商**火山引擎豆包**（Seedream 3.0/4.0 文生图 + SeedEdit 3.0 图生图）。同时修复了 Gemini 缺失 `requests` 导入与 MiniMax 返回值错位两个缺陷。

## 主要更新

### 模型目录扩展（`config/model_catalog.py`）

- **GPT-Image 家族扩展至 6 个型号**：新增 `gpt-image-2.5-flare`（快速高质量日常生图）与 `gpt-image-2.5-sunburst`（最强图像生成与编辑），保留 gpt-image-1/1-mini/1.5/2。默认模型从 `gpt-image-1` 切换至 `gpt-image-2`；gpt-image-1 系列标记为 Legacy（UI 显示"旧版"标签，默认不选中）。
- **Gemini Nano Banana 家族扩展至 4 个型号**：新增 `gemini-3.1-flash-lite-image`（Nano Banana 2 Lite，轻量快速）与 `gemini-3-pro-image`（Nano Banana Pro，最强画质）。默认从 `gemini-2.5-flash-image`（v1，2026-10 下线）切换至 `gemini-3.1-flash-image`（Nano Banana 2）；v1 标记为弃用。
- **新增人类可读名称映射**：`GPT_IMAGE_NAMES`、`GEMINI_IMAGE_NAMES`、`ARK_IMAGE_NAMES` 三组字典，UI 下拉显示友好名称（如"GPT-Image 2.5 Sunburst (最强)"），内部仍使用 stable model ID。

### 新增付费供应商：火山引擎豆包

- **`services/providers/volcengine_ark.py`**：接入火山引擎 Ark 平台，支持 3 个模型——`doubao-seedream-3-0-t2i`（文生图 3.0）、`doubao-seedream-4-0-t2i`（文生图 4.0，默认）、`doubao-seededit-3-0-i2i`（图生图 3.0）。端点 `ark.cn-beijing.volces.com`，Bearer <REDACTED> 认证，响应支持 `data[].url` 与 `data[].b64_json` 双格式。
- 内置串行锁（最小间隔 1.5s）防批量并发触发速率限制；3 次指数退避重试；120s 超时。
- 配置项：`volcengine_key`（API Key）。

### 配置向导升级（`ui/wizard_paid.py` v3）

- **GPT-Image 模型选择**：下拉框使用人类可读名称，支持 6 个型号切换。
- **新增豆包配置节**：API Key 输入 + 模型选择（Seedream 3.0/4.0 + SeedEdit 3.0）。
- 窗口布局精简（820×720），移除未使用的 i18n 绑定。

### 缺陷修复

- **gemini.py**：补全 `import requests`，修复 `RequestException` 处理器因缺少导入导致的 `NameError`。
- **minimax_image.py**：移除错位放置的 `return image_bytes`（引用了未定义的 `image_bytes`），修复特定错误路径下的 `F821` 未定义名称问题。

### 测试

- **新增 `tests/test_new_providers.py`（25 项）**：覆盖 model_catalog 常量完整性（GPT-Image 6 型号、Gemini 4 型号、豆包 3 型号）、默认值正确性、Legacy/弃用标记、人类可读名称映射、以及 volcengine_ark 的 mock HTTP 测试。

## 下载与安装

- **安装包**：下载 `text2image_pro_v2.3.1.exe`，运行后按向导安装。
- **便携版**：下载 `text2image_pro.exe`，无需安装即可直接运行。
- 现有用户的配置（`~/2image/config.json`）和历史记录（`~/2image/history.db`）完全兼容；GPT-Image 与 Gemini 的默认模型已自动升级，无需手动修改。如需使用豆包，需在付费配置向导中填写 `volcengine_key`。
