# 2image v2.7.1

本次更新修复界面语言切换功能：所有 UI 文案已全面接入 i18n 系统，简中/英文切换后各面板（菜单、向导、对话框、状态栏等）均正确显示对应语言，不再出现中文硬编码残留。

## 主要更新

### 界面语言切换修复

- **全面 i18n 覆盖**：`ui/` 下 13 个面板文件、`services/application/` 下 2 个控制器中的所有硬编码中文文案已替换为 `_()` 语言键调用，涵盖菜单栏、批量变体面板、队列面板、图片查看器、主内容区、历史侧栏、提示词片段库、免费/付费/LLM 配置向导、提示词助手、统计看板等全部 UI 组件。
- **新增 400+ 翻译键**：`config/i18n.py` 的 STRINGS 字典从 226 键扩展至 658 键，所有键均提供 `zh-CN` 与 `en` 双语言对照，键集合由 `tools/check_i18n.py` 全量对齐校验。
- **模型显示名称国际化**：GPT-Image、Gemini Nano Banana、豆包 Seedream/SeedEdit 等模型的人类可读名称已支持双语显示。
- **修复变量覆盖缺陷**：`ui/prompt_wizard.py` 中 `_` 局部变量覆盖 i18n 函数的问题已修复，确保模板应用后状态消息正确本地化。

## 下载与安装

- **安装包**：下载 `2image-setup-v2.7.1.exe`，运行后按向导安装。
- **便携版**：下载 `2image-portable-v2.7.1.exe`，无需安装即可直接运行。
- 配置、历史数据库、标签、图片与词库完全兼容，升级后无需任何手动操作。
- 语言切换在 **设置 → 界面语言** 中选择，重启应用后生效。
