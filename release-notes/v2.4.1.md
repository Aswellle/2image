# 2image v2.4.1

本次更新为 v2.4.0 的紧急修复版：修复了 v2.4.0 安装包与便携版**启动即报错**（"未处理的异常在脚本里"，`AttributeError: 'App' object has no attribute '_reset_view'`）的问题，并顺带消除了同源的两处潜在崩溃点。不包含任何新功能，从 v2.3.1 及更早版本升级的用户可直接跳过 v2.4.0 使用本版。

## 主要更新

### 缺陷修复

- **修复启动即崩溃（v2.4.0 全部构建包受影响）**：v2.4.0 前的界面重构误删了 `App._reset_view`（侧栏"重置视图"按钮的回调）方法，侧栏构建时直接引用不存在的属性导致主窗口尚未显示就抛出 `AttributeError`。已恢复该方法（重置筛选状态、清空主界面并刷新历史列表）。
- **修复状态栏更新崩溃**：同一次重构还误删了 `App._st`（状态栏文字与颜色更新）方法，修复启动问题后首次生成/选择历史条目即会触发该缺陷。已恢复。
- **修复字符计数联动失效**：`App._update_char_count`（词库面板插入词条后刷新输入框字数统计的转发方法）同样在重构中丢失，词库追加词条时字符计数不会更新。已恢复。
- **防回归**：新增协议一致性静态测试（13 项），校验面板声明的接口方法与 `self.app.*` 引用必须真实存在于 `App` 上——本次三个缺失方法在此测试下全部现形，杜绝同类漂移再次漏网。

## 下载与安装

- **安装包**：下载 `text2image_pro_v2.4.1.exe`，运行后按向导安装。
- **便携版**：下载 `text2image_pro.exe`，无需安装即可直接运行。
- 已下载 v2.4.0 的用户请替换为本版；配置和历史记录完全兼容，无需任何手动操作。

## 验证

- GitHub Actions：Ubuntu 质量门禁 + Windows 测试（3.11/3.12 双矩阵）+ Windows 构建三阶段。
- 完整测试套件：461 项通过，0 失败（新增协议一致性回归测试 13 项）。
- 启动冒烟验证：真实构造主窗口并调用 `_reset_view` / `_st` / `_update_char_count` 全部通过。
