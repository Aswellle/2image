# 2image v2.9.0

本次更新的主线是**模型时效性升级与配置可用性完善**：对全部 23 个生图接口逐一对照官方模型表与 API 文档做了时效性核查，废弃、过时、已从官方在册移除的模型全部下线并替换为现役版本（其中 4 个接口的默认模型此前会直接报错），配置向导的供应商信息、模型清单、计费口径与链接同步修正；同时 AI 提示词助手完成模型现代化，错误反馈全面升级为「可认知、可理解、可行动」的三层呈现。全部改动对配置、历史数据库、标签、图片与词库完全兼容。

## 主要更新

### 模型时效性升级

- **四个接口的默认模型此前会直接报错，本次全部修复**：火山豆包的 `-t2i` 后缀 ID（4.0 起官方只收带日期快照）、xAI 的已下架 `-quality` 模型、OpenRouter 的不在册默认、HuggingFace 的已下架 schnell——升级后默认路径全部落在现役模型上。
- **存量配置自动归一化**：配置里保存的已废弃模型 ID 会自动迁移到对应现役默认（记入调试日志可追溯），不会带着旧 ID 去撞 404；xAI 与通义万相支持手改 config.json 指定官方上新模型（按配置原样请求，自救助手）。
- **提示词助手模型现代化**：LLM 降级链更新为 DeepSeek-V3.2 → V3.1-Terminus → Qwen3-8B；DeepSeek 官方预设改用现役 `deepseek-flash`（V4.1-Flash，高性价比）与 `deepseek-v4-pro`，恰好 3 个预设可选。
- **新增调色板护栏之外的模型目录护栏**：图像模型「目录 ↔ 默认值 ↔ provider ↔ 向导下拉」四方一致性锁定，新增错误码缺指引、LLM 链展示漂移均会在测试层失败。

### 配置可用性完善

- **配置向导信息全面核对**：以官方文档逐项校验 23 个接口的模型清单、计费口径（Stability 改官方积分制口径，原数值错了十倍）、注册/取 Key 链接（ModelsLab 与 BFL 的旧链接已 404）与步骤指引，废弃过时表述全部清理。
- **错误反馈可行动**：生成失败现在按错误类型给出「下一步怎么做」——弹窗（仅在需要离开应用处理的配置/鉴权/配额类出现）正文附带指引，调试日志每条失败记录结构化为 `code=接口=错误=下一步` 可检索格式，全链失败时日志尾部给出最终原因总结。
- **图生图强度滑杆按接口能力显隐**：滑杆只对真正消费强度参数的接口（Stability SD3 图生图）显示，Gemini/豆包/BFL 等原生编辑接口下不再出现可调却无效的控件。
- **信息卡自适应换行**：配置向导的信息卡长行按容器宽度折行，窄窗口不再被截断。
- **提示词助手配置瘦身**：预设收敛为 3 个（硅基流动自动 / DeepSeek Flash / DeepSeek Pro），移除已死的 HuggingFace 兜底通道与冗余文案。

### 界面与文档

- 免费 / 付费 / 提示词助手三个配置向导的版式遵循既有令牌体系，密钥输入、模型下拉、链接按钮布局统一。
