# 2image v2.5.0

本次更新以国际化与界面可用性为核心：新增**界面语言切换器**（简体中文/繁體中文/English），顶部菜单栏全面重整并接入多语言；操作反馈引入**右下角 Toast 瞬态通知**，补全常用**键盘快捷键**；历史侧栏获得滚动、搜索、布局记忆与右键菜单等多项体验优化，缩略图加载管线重写后快速滚动不再卡顿；提示词助手默认只展示核心维度，界面统一为暗色主题。

## 主要更新

### 界面语言与菜单

- **语言切换器**：顶部菜单"设置 → 语言"新增简体中文/繁體中文/English 三选切换，偏好设置对话框同步提供语言选择项，选择后写入配置、重启应用生效。
- **菜单栏重整**：顶部菜单重组为 文件/工具/接口配置/数据/设置 五组；新增"文件"菜单聚合图片查看器、另存为、导出与清空日志；全部菜单项文案接入多语言。
- **多语言覆盖扩展**：翻译表扩展至 154 键 × 3 语言，并新增硬编码文案防回潮门槛（744 条存量基线）。

### 操作反馈与快捷键

- **Toast 瞬态通知**：右下角新增自动消失的轻量通知组件，批量变体与任务入队等操作的反馈不再依赖状态栏文字，不打断当前操作。
- **键盘工作流补全**：`Ctrl+Shift+P` 呼出提示词助手、`Esc` 关闭图片查看器等覆盖窗口、`Delete` 删除选中的历史条目、`←`/`→` 在历史列表中快速导航；输入框聚焦时快捷键自动让位，不会误触发。

### 历史侧栏体验

- **滚动与搜索优化**：滚轮滚动按行归一化，鼠标与触控板步进一致；搜索框新增一键清除按钮；启用筛选时显示筛选状态条；刷新后保持原有滚动位置，长列表不再跳回顶部。
- **侧栏布局记忆**：侧栏宽度调整后自动记住，支持一键折叠收起；双击分隔条恢复默认宽度。
- **右键菜单重排**：常用操作（查看大图、在文件夹中显示）置顶，重命名与打标居中，删除等危险操作殿后并加分隔隔离；新增"在文件夹中显示"直接定位图片文件。

### 性能

- **缩略图加载管线重写**：解码结果二级缓存 + 优先级队列 + 取消令牌，快速滚动历史列表时优先加载可视区域、跳过已滚离的请求，重复解码显著减少；加载工作线程与界面组件完全隔离，滚动保持流畅。

### 提示词助手

- **维度参数渐进披露**：AI 提示词生成默认只展示风格与氛围两个核心维度，受众、构图、光影、色彩、细节五维折叠进"高级选项"按需展开，界面更聚焦。
- **视觉统一**：助手面板头部与配色改用全局设计令牌，与主界面完全同调，清除突兀的独立配色。

### 主题精简

- **统一暗色主题**：界面仅保留暗色模式，移除浅色主题及其切换基础设施；全局配色收敛为单一语义令牌体系（设计令牌由主题派生），视觉一致性与可维护性提升。

### 开发者可见

- **测试套件扩至 514 项**：新增语言切换（8 项）、协议一致性（13 项）、缩略图管线、Toast 组件、侧栏交互与布局等回归测试；测试进程与真实用户配置完全隔离，杜绝测试覆写本机数据。
- **稳定性修复**：历史侧栏销毁时正确关闭缩略图加载线程，修复线程泄漏；Windows 下测试进程复用共享 Tk 根实例，消除解释器反复创建销毁引发的崩溃。
- **CI 动作升级**：checkout@v5、setup-python@v6，消除非阻塞版本告警。

## 下载与安装

- **安装包**：下载 `text2image_pro_v2.5.0.exe`，运行后按向导安装。
- **便携版**：下载 `text2image_pro.exe`，无需安装即可直接运行。
- 配置与历史记录完全兼容，升级后无需任何手动操作。界面统一为暗色主题；如需切换界面语言，请在顶部菜单"设置 → 语言"中选择并重启应用。
